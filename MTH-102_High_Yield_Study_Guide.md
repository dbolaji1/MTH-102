## 2. Definitions and Laws

|---|---|---|---|---|
| Real-Valued Function | A mathematical construct or rule that associates each element from a domain set (typically real numbers) with a unique real number in the codomain (range). For each input $x$, there is exactly one output $f(x)$. | `10864-Elementary+Mathematics+II+29.pdf / 8473-Week+1_+Working+with+Real-Valued+Functions.pdf` | p. 47, §1.1 / slide 5 | Yes |

| Injective (One-to-One) Function | A function is injective if different inputs always produce different outputs: $f(a) = f(b) \implies a = b$. In other words, no element in the codomain is mapped to by more than one domain element. | `10864-Elementary+Mathematics+II+29.pdf / 8475-Week+2_+How+to+Graph+Functions+29.pdf` | p. 47, §1.1 / slide 5 | Yes |
| Surjective (Onto) Function | A function is surjective if every element in the codomain is mapped to by at least one element in the domain, meaning the actual range of the function is equal to its codomain. | `8475-Week+2_+How+to+Graph+Functions+29.pdf` | slide 5 | Yes |
| Bijective Function | A function that is both injective (one-to-one) and surjective (onto). This mapping creates a perfect one-to-one correspondence between the domain and codomain sets. | `8475-Week+2_+How+to+Graph+Functions+29.pdf` | slide 5 | Yes |
| Vertical Line Test | A graphical test used to determine if a curve on a graph represents a function. If any vertical line intersects the curve at more than one point, the curve represents a relation; if every vertical line intersects at most once, it represents a function. | `8475-Week+2_+How+to+Graph+Functions+29.pdf` | slide 6 | Yes |
| Composite Function | A function $h(x) = f(g(x))$, represented as $(f \circ g)(x)$, formed by evaluating the function $f$ at the output of another function $g$. | `10864-Elementary+Mathematics+II+29.pdf / 8473-Week+1_+Working+with+Real-Valued+Functions.pdf` | p. 41, §1.4.6 / slide 20 | Yes |
| Inverse Function | A function $f^{-1}(y)$ that reverses the action of $f(x)$, satisfying $f^{-1}(f(x)) = x$ and $f(f^{-1}(y)) = y$. It exists if and only if the original function $f$ is injective. | `8473-Week+1_+Working+with+Real-Valued+Functions.pdf` | slide 19 | Yes |
| Limit of a Function (Informal) | The value $L$ that a function $f(x)$ approaches as its independent input $x$ approaches a particular value $a$ (without $x$ needing to equal $a$ itself). Written as $\lim_{x \to a} f(x) = L$. | `10864-Elementary+Mathematics+II+29.pdf` | p. 10, §1.1.1 / Glossary p. 129 | Yes |
| Formal Definition of Limit ($\epsilon-\delta$) | We say $\lim_{x \to a} f(x) = L$ if $f(x)$ is defined on an interval containing $a$ (except possibly at $a$) and for every $\epsilon > 0$ there exists a $\delta > 0$ such that $0 < |x - a| < \delta \implies |f(x) - L| < \epsilon$. | `10864-Elementary+Mathematics+II+29.pdf` | p. 14, §1.1.3 | Yes |
| Left-Hand Limit | The value $L$ that $f(x)$ approaches as $x$ approaches $a$ through values strictly smaller than $a$ ($x < a$). Written as $\lim_{x \to a^-} f(x) = L$. | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 19, §1.1.4 / slide 11 | Yes |
| Right-Hand Limit | The value $L$ that $f(x)$ approaches as $x$ approaches $a$ through values strictly larger than $a$ ($x > a$). Written as $\lim_{x \to a^+} f(x) = L$. | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 19, §1.1.5 / slide 11 | Yes |
| Theorem on Existence of Limit | A two-sided limit $\lim_{x \to a} f(x) = L$ exists if and only if both the left-hand limit and right-hand limit exist and are equal: $\lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L$. | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 20, §1.1.6 / slide 13 | Yes |
| Limit at Infinity | The value $L$ that $f(x)$ approaches as the input variable $x$ grows without bound towards positive infinity ($x \to \infty$) or negative infinity ($x \to -\infty$). | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 21, §1.1.7 / slide 15 | Yes |
| Limit Laws / Properties of Limits | Fundamental algebraic rules establishing that limits can be taken term-by-term for sums, differences, constant multiples, products, quotients, powers, roots, and reciprocals, provided the individual limits exist. | `10864-Elementary+Mathematics+II+29.pdf / 8477-Week+3_+Evaluating+Limit+Algebraically+29.pdf` | pp. 22-26, §1.2 / slides 14-24 | Yes |
| Limits and Inequalities Theorem | Let $f$ and $g$ be functions whose limits as $x \to a$ exist. If $f(x) \leq g(x)$ holds for all $x$ in an open interval around $a$ (except possibly at $a$), then $\lim_{x \to a} f(x) \leq \lim_{x \to a} g(x)$. | `10864-Elementary+Mathematics+II+29.pdf` | p. 35, §1.3.1 | Yes |
| Sandwich (Squeeze) Theorem | If $f(x) \leq g(x) \leq h(x)$ for all $x$ in an open interval containing $a$ (except possibly at $a$) and $\lim_{x \to a} f(x) = \lim_{x \to a} h(x) = L$, then $\lim_{x \to a} g(x) = L$. | `10864-Elementary+Mathematics+II+29.pdf / 8477-Week+3_+Evaluating+Limit+Algebraically+29.pdf` | p. 36, §1.3.2 / Glossary p. 129 / slide 23 | Yes |
| L'Hôpital's Rule | A rule stating that if a limit $\lim_{x \to a} \frac{f(x)}{g(x)}$ yields an indeterminate form $\frac{0}{0}$ or $\frac{\infty}{\infty}$, then $\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$, provided the derivatives exist and $g'(x) \neq 0$. | `8477-Week+3_+Evaluating+Limit+Algebraically+29.pdf` | slide 12 | Yes |
| Continuity of a Function at a Point | A function $f(x)$ is continuous at a point $c$ in its domain if: (1) $f(c)$ is defined, (2) $\lim_{x \to c} f(x)$ exists, and (3) $\lim_{x \to c} f(x) = f(c)$. Graphically, it means there is no gap, jump, or hole at $c$. | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 38, §1.4 / Glossary p. 128 / slide 6 | Yes |
| Continuity of Polynomials | A theorem stating that any polynomial function of the form $P(x) = c_n x^n + \dots + c_1 x + c_0$ is continuous everywhere on the real line $\mathbb{R}$. | `10864-Elementary+Mathematics+II+29.pdf` | p. 38, §1.4.1 / Glossary p. 129 | Yes |
| Continuity of Rational Functions | A theorem stating that any rational function $R(x) = \frac{P(x)}{Q(x)}$ is continuous at every point in its domain (i.e., at all points $x$ where $Q(x) \neq 0$). | `10864-Elementary+Mathematics+II+29.pdf` | p. 39, §1.4.2 / Glossary p. 129 | Yes |
| Removable Discontinuity (Hole) | A discontinuity at $x=c$ where $\lim_{x \to c} f(x)$ exists but either $f(c)$ is undefined or $f(c) \neq \lim_{x \to c} f(x)$. It is named 'removable' because it can be filled by defining or redefining $f(c) = \lim_{x \to c} f(x)$. | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 39, §1.4.3 / slide 16 | Yes |
| Jump Discontinuity | A discontinuity at $x=c$ where the left-hand limit and right-hand limit exist as finite real numbers but are not equal ($\lim_{x \to c^-} f(x) \neq \lim_{x \to c^+} f(x)$), causing a step or jump in the function's graph. | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 39, §1.4.3 / slide 18 | Yes |
| Infinite Discontinuity | A discontinuity at $x=c$ where the function values grow without bound towards $+\infty$ or $-\infty$ as $x$ approaches $c$ from either the left or right, creating a vertical asymptote at $x=c$. | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 39, §1.4.3 / slide 17 | Yes |
| Essential (or Oscillatory) Discontinuity | A discontinuity at $x=c$ where the limit does not exist because the function oscillates with extreme, infinite frequency as $x \to c$ (e.g., $f(x) = \sin(1/x)$), or because one or both one-sided limits do not exist and are not infinite. | `10864-Elementary+Mathematics+II+29.pdf / 8471-Week+4_+Evaluating+Limits+Graphically+29.pdf` | p. 40, §1.4.3 / slide 10 | Yes |
| Composition of a Continuous Function and a Limit Theorem | If $\lim_{x \to a} g(x) = L$ and the function $f$ is continuous at $L$, then the limit can pass inside the function: $\lim_{x \to a} f(g(x)) = f(\lim_{x \to a} g(x)) = f(L)$. | `10864-Elementary+Mathematics+II+29.pdf` | p. 41, §1.4.7 / Glossary p. 128 | Yes |
| Trigonometric Limit Theorems | The special limiting behaviors of trigonometric functions as the angle approaches zero, specifically $\lim_{\theta \to 0} \frac{\sin \theta}{\theta} = 1$ and $\lim_{\theta \to 0} \cos \theta = 1$. | `10864-Elementary+Mathematics+II+29.pdf` | pp. 45-46, §1.4.8-1.4.9 | Yes |
| Derivative of a Function (First Principles) | The rate at which a function's value changes with respect to its independent variable, defined as a limit of the difference quotient: $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$. | `10864-Elementary+Mathematics+II+29.pdf / 8514-Week+5_+Differentiation_+Formulae26+Examples+29+29.pdf` | p. 49, §2.1 / Glossary p. 128 / slides 17-19 | Yes |
| Differentiability | The property of a function being differentiable, meaning its derivative exists at each point in its domain.
